Đặt các file .mp3 (hoặc .m4a / .wav đều được, chỉ cần đổi đúng phần đuôi
tương ứng trong app.js nếu bạn dùng đuôi khác mp3) vào ĐÚNG thư mục này
(audio/) với ĐÚNG tên như bên dưới. App sẽ tự nhận, không cần sửa code.

Nếu một file chưa có, app vẫn chạy bình thường — chỉ phát tiếng chuông,
bỏ qua phần giọng nói, không báo lỗi.

CÁCH ĐƯA FILE LÊN GITHUB:
- Vào repository trên GitHub -> mở thư mục audio -> "Add file" -> "Upload files"
- Kéo thả các file .mp3 đã đặt đúng tên ở trên vào -> Commit changes.
- Mở lại app một lần khi có mạng để app tải và lưu cache các file mới này,
  sau đó dùng offline bình thường.
